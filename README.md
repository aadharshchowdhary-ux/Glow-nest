# GlowNest Salon Website

A responsive static website demo for GlowNest Salon.

## Files
- index.html — website structure/content
- style.css — responsive styling
- script.js — mobile navigation, service selection and demo booking form

## Run
Open `index.html` in a browser.

## Customise
Replace the visual placeholders in `index.html` with real salon images, update the phone/address/email, and connect the booking form to a real backend or WhatsApp workflow before production.
